# 三维曲面网格生成模块详细设计文档

## 1. 概述

### 1.1 模块名称
`sfmesh` - Surface Mesh Generation Module

### 1.2 模块功能
基于阵面推进法（Advancing Front Method）的三维曲面三角形网格生成模块，支持从 IGES/STEP 几何模型生成高质量曲面网格。

### 1.3 设计目标
- 支持从 IGES/STEP 文件导入几何模型
- 使用阵面推进法生成三角形曲面网格
- 支持基于曲率的自适应尺寸控制
- 提供网格质量评估和优化功能
- 与现有 `adfront2` 二维网格生成模块保持架构一致性

## 3. 核心数据结构

### 3.1 NodeElement3D - 三维节点元素

**文件位置**: `surface_front.py`

**功能描述**: 表示曲面网格中的三维节点，包含几何位置、拓扑信息和属性数据。

**数据成员**:

| 成员名 | 类型 | 描述 |
|--------|------|------|
| `coords` | Tuple[float, float, float] | 节点三维坐标 (x, y, z) |
| `idx` | int | 节点全局索引 |
| `bc_type` | str | 边界类型（如 "wall", "interior"） |
| `part_name` | str | 所属部件名称 |
| `surface` | TopoDS_Face | 所属 OCC 曲面对象 |
| `uv_params` | Tuple[float, float] | 曲面参数坐标 (u, v) |
| `normal` | Tuple[float, float, float] | 节点法向量 |
| `hash` | int | 基于坐标的哈希值，用于快速比较 |
| `bbox` | Tuple[float, ...] | 边界框 (x_min, y_min, z_min, x_max, y_max, z_max) |

**设计要点**:
- 使用 `__slots__` 优化内存占用
- 哈希值基于坐标计算，支持快速去重
- 边界框用于空间索引，格式为 6 元组

### 3.2 SurfaceTriangle - 曲面三角形单元

**文件位置**: `surface_front.py`

**功能描述**: 表示曲面上的三角形单元，自动计算几何属性和质量指标。

**数据成员**:

| 成员名 | 类型 | 描述 |
|--------|------|------|
| `nodes` | List[NodeElement3D] | 三个顶点节点列表 |
| `node_ids` | List[int] | 节点索引列表 |
| `idx` | int | 单元全局索引 |
| `surface` | TopoDS_Face | 所属曲面 |
| `normal` | np.ndarray | 三角形法向量 |
| `area` | float | 三角形面积 |
| `quality` | float | 形状质量因子 (0~1) |
| `bbox` | Tuple[float, ...] | 边界框 |

**质量计算公式**:

```
quality = 4 * sqrt(3) * area / (a² + b² + c²)
```

其中 a, b, c 为三角形边长，quality = 1 表示等边三角形。

### 3.3 SurfaceFront - 三维曲面阵面

**文件位置**: `surface_front.py`

**功能描述**: 表示曲面上的边界边，是阵面推进法的核心数据结构。

**数据成员**:

| 成员名 | 类型 | 描述 |
|--------|------|------|
| `node_elems` | List[NodeElement3D] | 两端节点 |
| `idx` | int | 阵面索引 |
| `bc_type` | str | 边界类型 |
| `surface` | TopoDS_Face | 所属曲面 |
| `priority` | bool | 优先级标志 |
| `al` | float | 搜索范围系数 |
| `center` | Tuple[float, ...] | 阵面中心坐标 |
| `length` | float | 阵面长度 |
| `direction` | Tuple[float, ...] | 方向向量 |
| `normal` | Tuple[float, ...] | 平均法向量 |
| `tangent_normal` | Tuple[float, ...] | 切平面内的推进方向 |
| `bbox` | Tuple[float, ...] | 边界框 |

**关键方法**:

- `__lt__`: 优先队列比较，优先级高或长度短的阵面优先处理
- `_compute_tangent_normal()`: 计算切平面内的法向，用于确定推进方向

**推进方向计算**:

```
tangent_normal = cross(direction, surface_normal)
```

该方向垂直于阵面方向且位于曲面切平面内。

## 4. 核心算法

### 4.1 阵面推进法主流程

**文件位置**: `surface_mesh.py`

**算法流程图**:

```
┌─────────────────────────────────────────────────────────────────┐
│  Step 1: 几何模型导入与预处理                                      │
│  ─────────────────────────────────────────────────────────────── │
│  • 读取 IGES/STEP 文件                                           │
│  • 提取所有曲面 (TopoDS_Face)                                     │
│  • 提取曲面边界曲线                                               │
│  • 构建曲面拓扑邻接关系                                           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 2: 边界离散化生成初始阵面                                    │
│  ─────────────────────────────────────────────────────────────── │
│  • 对每条边界曲线按尺寸场离散                                       │
│  • 创建边界节点 (NodeElement3D)                                    │
│  • 创建初始阵面 (SurfaceFront)                                     │
│  • 按长度排序入堆 (heapq)                                          │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 3: 阵面推进主循环                                           │
│  ─────────────────────────────────────────────────────────────── │
│  while front_list:                                               │
│      1. 弹出最短阵面 base_front                                    │
│      2. 计算理想点 pbest (在曲面上)                                │
│      3. 搜索候选节点 (3D RTree)                                    │
│      4. 选择最佳节点 (质量评估 + 曲面投影)                         │
│      5. 相交检查 (3D 空间)                                        │
│      6. 更新阵面、节点、单元                                       │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 4: 后处理与输出                                             │
│  ─────────────────────────────────────────────────────────────── │
│  • 网格质量评估                                                   │
│  • 输出 VTK 格式                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 理想点计算算法

**文件位置**: `surface_geometry.py` - `compute_ideal_point_on_surface()`

**算法描述**:

1. 计算阵面中心点
2. 获取推进距离（基于尺寸场）
3. 计算推进方向（切平面法向）
4. 计算三维空间中的理想点
5. 将理想点投影到曲面上
6. 迭代优化直到收敛

**伪代码**:

```python
def compute_ideal_point_on_surface(front, distance, surface):
    # 1. 获取阵面中心
    center = front.center
    
    # 2. 获取推进方向
    tangent_normal = front.tangent_normal
    
    # 3. 计算三维理想点
    ideal_point_3d = center + distance * tangent_normal
    
    # 4. 投影到曲面
    uv = project_point_to_surface(ideal_point_3d, surface)
    
    # 5. 迭代优化
    for _ in range(max_iterations):
        projected_point = evaluate_point(uv, surface)
        if distance(projected_point, ideal_point_3d) < tolerance:
            break
        uv = project_point_to_surface(ideal_point_3d, surface)
        ideal_point_3d = projected_point
    
    return projected_point, uv
```

### 4.3 候选点搜索算法

**文件位置**: `surface_mesh.py` - `_search_candidates()`

**算法描述**:

1. 计算搜索半径 = al × spacing
2. 使用 3D RTree 进行范围查询
3. 过滤无效候选点（阵面端点）
4. 返回候选节点列表

**空间索引优化**:

使用 RTree 进行三维空间索引，查询复杂度 O(log n)。

### 4.4 最佳节点选择算法

**文件位置**: `surface_mesh.py` - `_select_best_node()`

**算法描述**:

1. 遍历候选节点
2. 计算与阵面形成的三角形质量
3. 创建理想点作为候选
4. 按质量排序选择最佳节点

**质量评估函数**:

```python
def _compute_triangle_quality(p0, p1, p2):
    a = ||p1 - p0||
    b = ||p2 - p1||
    c = ||p0 - p2||
    
    s = (a + b + c) / 2
    area = sqrt(s * (s-a) * (s-b) * (s-c))
    
    quality = 4 * sqrt(3) * area / (a² + b² + c²)
    return quality
```

## 5. 曲面几何操作

### 5.1 SurfaceGeometry 类

**文件位置**: `surface_geometry.py`

**核心方法**:

| 方法名 | 功能 | 输入 | 输出 |
|--------|------|------|------|
| `project_point_to_surface()` | 点投影到曲面 | 3D点, 曲面 | 参数(u,v) |
| `evaluate_point()` | 计算曲面点 | 参数(u,v), 曲面 | 3D坐标 |
| `get_surface_normal()` | 获取曲面法向 | 参数(u,v), 曲面 | 法向量 |
| `get_surface_curvature()` | 获取曲率信息 | 参数(u,v), 曲面 | (平均曲率, 高斯曲率, 最大曲率) |
| `get_surface_derivatives()` | 获取切向量 | 参数(u,v), 曲面 | (du方向, dv方向) |
| `compute_ideal_point_on_surface()` | 计算理想点 | 阵面信息 | 理想点坐标 |

**OpenCASCADE 接口映射**:

| 功能 | OCC 类 |
|------|--------|
| 点投影 | `GeomAPI_ProjectPointOnSurf` |
| 曲面属性 | `GeomLProp_SLProps` |
| 曲面适配器 | `BRepAdaptor_Surface` |
| 曲面求值 | `BRep_Tool.Surface()` |

### 5.2 曲率计算

**曲率类型**:

- **平均曲率 (Mean Curvature)**: H = (k1 + k2) / 2
- **高斯曲率 (Gaussian Curvature)**: K = k1 × k2
- **最大主曲率 (Max Principal Curvature)**: max(|k1|, |k2|)

**曲率自适应尺寸计算**:

```python
def _compute_curvature_based_spacing(u, v, surface):
    mean_curv, gauss_curv, max_curv = get_surface_curvature(u, v, surface)
    
    if max_curv < 1e-12:
        return max_spacing
    
    radius = 1.0 / max_curv
    spacing = curvature_factor * radius
    
    return clip(spacing, min_spacing, max_spacing)
```

## 6. 尺寸场设计

### 6.1 SurfaceSizingField 类

**文件位置**: `sizing_field.py`

**功能**: 控制曲面网格的单元尺寸分布

**配置参数**:

| 参数名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| `global_spacing` | float | 1.0 | 全局网格尺寸 |
| `min_spacing` | float | 0.01 | 最小网格尺寸 |
| `max_spacing` | float | 100.0 | 最大网格尺寸 |
| `curvature_adaptation` | bool | True | 是否启用曲率自适应 |
| `curvature_factor` | float | 0.2 | 曲率自适应系数 |

**尺寸计算策略**:

```
spacing_at(point) = min(global_spacing, curvature_based_spacing)
```

### 6.2 AdaptiveSizingField 类

**扩展功能**: 支持特征点和特征线的局部细化

**特征类型**:

- **特征点**: 角点、尖点等
- **特征线**: 棱线、脊线等

**特征细化公式**:

```
spacing = global_spacing × ratio × (distance / radius + 0.1)
```

## 7. 网格质量评估

### 7.1 SurfaceMeshQuality 类

**文件位置**: `mesh_quality.py`

**质量指标**:

| 指标 | 计算方法 | 范围 | 理想值 |
|------|----------|------|--------|
| 形状质量 | 4√3×area/(a²+b²+c²) | 0~1 | 1 |
| 长宽比 | max_edge/(2√3×area/max_edge) | ≥1 | 1 |
| 最小角度 | 最小内角 | 0°~60° | 60° |
| 最大角度 | 最大内角 | 60°~180° | 60° |
| 雅可比 | 边向量叉积模 | >0 | 大 |

**质量阈值**:

- 质量因子 < 0.3: 低质量单元
- 最小角度 < 15°: 低质量单元
- 最大角度 > 150°: 低质量单元

### 7.2 相交检查

**检查类型**:

1. **边-三角形相交**: `check_edge_triangle_intersection()`
2. **三角形-三角形相交**: `check_triangle_intersection()`

**算法**: 基于分离轴定理（SAT）的快速相交检测

## 8. 与二维阵面推进法的对比

### 8.1 数据结构对比

| 概念 | 2D (adfront2) | 3D 曲面 (sfmesh) |
|------|---------------|------------------|
| 阵面 | 线段 `Front(node1, node2)` | 边界边 `SurfaceFront(node1, node2, face)` |
| 单元 | 三角形 `Triangle(p1, p2, p3)` | 三角形 `SurfaceTriangle(p1, p2, p3, surface)` |
| 法向 | 2D 法向 `(-dy, dx)` | 3D 曲面法向（从几何获取） |
| 理想点 | 2D 平面内计算 | 曲面上投影计算 |
| 几何约束 | 边界曲线 | 曲面 + 边界曲线 |
| 参数域 | 无需 | 可在参数域操作 |

### 8.2 算法差异

| 方面 | 2D 平面网格 | 3D 曲面网格 |
|------|-------------|-------------|
| **几何约束** | 边界曲线 | 曲面 + 边界曲线 |
| **理想点计算** | 平面内直接计算 | 需投影到曲面 |
| **法向计算** | 固定 `(-dy, dx)` | 曲面法向（变化） |
| **尺寸场** | 可不考虑曲率 | 需考虑曲率自适应 |
| **相交检查** | 2D 线段相交 | 3D 三角形相交 |
| **空间索引** | 2D RTree | 3D RTree |

## 9. 使用示例

### 9.1 从 IGES/STEP 文件生成网格

```python
from sfmesh import generate_surface_mesh_from_file

triangles = generate_surface_mesh_from_file(
    filename="model.step",
    global_spacing=1.0,
    output_vtk="output.vtk"
)
```

### 9.2 从 OCC 曲面对象生成网格

```python
from OCC.Core.BRepPrimAPI import BRepPrimAPI_MakeSphere
from OCC.Core.TopExp import TopExp_Explorer
from OCC.Core.TopAbs import TopAbs_FACE
from sfmesh import SurfaceMeshGenerator

# 创建球体
shape = BRepPrimAPI_MakeSphere(10.0).Shape()

# 获取曲面
explorer = TopExp_Explorer(shape, TopAbs_FACE)
face = explorer.Current()

# 生成网格
generator = SurfaceMeshGenerator(
    surface=face,
    global_spacing=1.0,
    curvature_adaptation=True
)
triangles = generator.generate()

# 导出
generator.export_to_vtk("sphere_mesh.vtk")
```

### 9.3 自定义尺寸场

```python
from sfmesh import SurfaceMeshGenerator, AdaptiveSizingField

# 创建自适应尺寸场
sizing = AdaptiveSizingField(
    global_spacing=2.0,
    min_spacing=0.1,
    max_spacing=5.0,
    curvature_adaptation=True,
    curvature_factor=0.3
)

# 添加特征点
sizing.add_feature_point(
    point=(0, 0, 0),
    refinement_radius=2.0,
    refinement_ratio=0.5
)

# 使用自定义尺寸场
generator = SurfaceMeshGenerator(
    surface=face,
    global_spacing=2.0
)
generator.sizing_field = sizing
triangles = generator.generate()
```
